# CareerTrack

### Smart Student Placement Management System

CareerTrack is a full-stack placement management platform designed to help students organize and manage their placement preparation in one place.

It provides features for managing student profiles, exploring companies, tracking job applications, practicing interview and technical questions, and monitoring preparation progress.

---

## 🚀 Features

### 👤 Student Profile
- Manage personal and academic information
- Add technical skills
- Add projects and certifications
- Add GitHub and LinkedIn profiles
- Track profile completion

### 🏢 Companies
- Explore multiple companies
- Search companies
- Filter companies by role and location
- View company details
- Save companies
- Access official company career pages

### 📋 Application Tracking
- Add job applications
- Track application status
- Manage application details
- Search and filter applications
- Track stages such as:
  - Applied
  - Shortlisted
  - Interview
  - Selected
  - Rejected

### 📚 Placement Preparation
Practice questions from multiple categories:

- Aptitude
- Java
- Data Structures & Algorithms
- Python
- SQL / DBMS
- Operating Systems
- Computer Networks
- Coding
- Interview

### 📊 Progress Tracking
- Track attempted questions
- Track correct and wrong answers
- Monitor preparation progress
- View overall preparation percentage
- View subject-wise progress

### 📈 Smart Dashboard
The dashboard provides an overview of:

- Applications
- Shortlisted applications
- Preparation progress
- Profile completion
- Application statistics
- Recent activities
- Quick actions
